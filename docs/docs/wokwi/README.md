# Wokwi Simulation

This folder contains the Wokwi simulation resources for the ESP32 EV
Battery Management System.

The simulations are used to verify the functionality of the embedded
software before physical hardware implementation.

## Simulation Components

- ESP32 DevKit
- Simulated battery-cell voltage inputs
- I2C 16x2 LCD
- LEDs
- Buzzer
- Relay
- Push buttons
- Breadboard connections

## Simulation Testing

The Wokwi simulations are used to test:

- Cell-voltage monitoring
- Battery imbalance detection
- Weakest and strongest cell identification
- Safety fault detection
- Relay protection
- LCD display operation
- Fault-state transitions
- Blynk connectivity
- Event-driven telemetry
- Battery-risk analysis
